# 段階0 訂正候補の独立評価の手順

対象：Issue #124。元にした計画書の節：`docs/plan.md` 3章（段階0の訂正候補の記録）、6章 段階0。

この文書は、Hermesが記録した訂正候補を、利用者が渡した材料だけで独立に評価する手順と、合成の例を示す。
段階の完了、スキルの読み取り、本番スキルへの反映、自動の採用は扱わない。採否とマージは利用者が決める。

## 1. 前提と禁止

- 評価に使うのは、**利用者がその評価のセッションに渡した材料だけ**とする。評価者は Discord、Hermes の会話履歴、`~/.hermes`、非公開の候補台帳、認証情報を直接読まない。足りない材料は利用者に求め、自分で取りに行かない。
- 評価は、設計の相談とは**別のセッション**で行う。HermesやClaude Codeとの設計の相談（#122、利用者の明示の依頼によるもの）は、独立評価に数えない。相談で聞いた内容を、評価の根拠に使わない。
- 評価の結果は、採否の判断材料であり、採用ではない。評価者は採否を決めず、候補台帳・③の台帳・スキルを書き換えない。
- 公開repoには、会話本文、実際の候補の中身、ローカルのパスや秘密情報を書かない。本文の例は合成である。

## 2. 3つの区分を混ぜない

評価の記録では、各項目を次の3つに分けて書く。1つの文に2つの区分を混ぜない。

| 区分 | 内容 | 書く人 |
| --- | --- | --- |
| A 自己申告 | Hermesが候補に書いた内容（当初の判断と根拠、訂正とその理由、原因や関係スキルの仮説） | 候補の記載をそのまま要約する |
| B 独立に確かめた事実 | 渡された材料だけから評価者が確かめられたこと。何で確かめたかを添える | 評価者 |
| C 原発言との照合 | 利用者が原発言を見て、候補と合っているかを判断した結果 | 利用者（評価者は代わりに書かない） |

A は確かめるまで事実として扱わない。原因や関係スキルは、B で確かめられても仮説のまま残す（スキルの中身は段階0では読まないため）。

## 3. 判定の値

各項目に次のどれかを付ける。

- `確認済み`：渡された材料で、自己申告と合うことを確かめた。
- `不一致`：渡された材料と、自己申告が食い違う。食い違いの箇所を書く。
- `保留`：渡された材料では確かめられない。何があれば確かめられるかを書く。推測で `確認済み` や `不一致` にしない。

C の欄は、利用者が照合するまで `保留（利用者の照合待ち）` とする。

## 4. 手順

1. 利用者が、新しいセッションで評価者に候補1件と、照合に使ってよい材料を渡す。
2. 評価者は、渡された材料の一覧を記録の冒頭に書く。それ以外の情報源は使わない。
3. 候補の各項目（元の発言への参照、当初の判断と根拠、訂正とその理由、次回の判定基準、未確認事項）について、A を要約し、B と判定の値を書く。
4. 次回の判定基準が、第三者が当否を決められる形になっているかを書く。なっていなければ、どこがあいまいかを書く。
5. 評価者の所見と、利用者に確かめてほしい点を書く。採否の推奨は書いてよいが、決定ではないと明記する。
6. 利用者が原発言と照合して C を埋め、採否を決める。段階2に進める訂正だけを、利用者が③の台帳に手で登録する。

## 5. 合成の例

次は架空の候補である。実際の会話や候補台帳の記録ではない。

**候補 `example-0001`（合成）**

| 項目 | A 自己申告 | B 独立に確かめた事実 | 判定 | C 原発言との照合 |
| --- | --- | --- | --- | --- |
| 元の発言への参照 | 「架空チャンネル、架空日時の利用者の発言」 | 渡された抜粋に同じ日時の発言がある | 確認済み | 保留（利用者の照合待ち） |
| 当初の判断と根拠 | 依頼を「要約」と解釈した。理由は「まとめて」という語 | 抜粋の依頼文に「まとめて」があり、Hermesの応答も要約形式。ただし解釈の内面は確認できない | 保留（判断理由） | 保留（利用者の照合待ち） |
| 訂正とその理由 | 利用者は箇条書きの一覧を求めていた | 抜粋の次の発言に「一覧で」とある | 確認済み | 保留（利用者の照合待ち） |
| 次回の判定基準 | 「まとめて」で形式が不明なら、形式を1回確かめる | 第三者が当否を決められる形 | 確認済み | 保留（利用者の照合待ち） |
| 原因・関係スキル（仮説） | 要約用のスキルが既定で文章形式を選ぶ | スキルの中身は渡されておらず、段階0では読まない | 保留 | 保留（利用者の照合待ち） |
| 未確認事項 | 同じ言い方が他の依頼でも起きるか | 渡された材料は1件だけで、頻度は確かめられない | 保留 | 保留（利用者の照合待ち） |

- 使った材料：利用者が渡した候補1件と、前後3発言の抜粋（合成）。
- 所見：記載と抜粋は合う。原因の仮説は確かめられない。
- 利用者に確かめてほしい点：抜粋が原発言の前後を欠けなく含むか。
- 採否：評価者は決めない。利用者が決める。
